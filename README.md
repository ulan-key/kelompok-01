# SOP Pencatatan Kas

Repo ini menyimpan dokumen dan berkas pendukung untuk pencatatan kas kecil di bagian keuangan. Semua perubahan dokumen tercatat lengkap, jadi kalau ada aturan yang direvisi, riwayatnya bisa ditelusuri kapan diubah dan siapa yang mengubah.

## Isi repo

| Berkas | Keterangan |
|---|---|
| `sop-kas-kecil.md` | Aturan dan alur pengajuan kas kecil |
| `jurnal-umum.csv` | Contoh pencatatan transaksi bulan berjalan |
| `makro-rekap.txt` | Makro Excel untuk merekap sheet bulanan |
| `daftar-kode-akun.md` | Daftar kode akun beserta cara pencatatannya |
| `index.html` | Halaman profil yang ditampilkan lewat GitHub Pages |

## Cara pakai

Buka berkas yang ingin dibaca langsung di halaman ini. Untuk mengubah isinya, klik ikon pensil di pojok kanan atas berkas, lakukan perubahan, lalu isi keterangan singkat sebelum menyimpan.

## Kontak

Dikelola oleh bagian keuangan. Pertanyaan dan usulan perubahan aturan silakan tulis di tab Issues.
